# Portfolio Story

## Problem

Families and teams manage schedules, groceries, health reminders, travel, bills, and planning across disconnected tools.

## Solution

A multi-agent system where each agent owns a domain and an orchestrator coordinates them.

## What makes it portfolio-worthy

- Real architecture, not just prompting
- Memory layer
- RAG retrieval
- Tool execution
- Background jobs
- API + UI
- Dockerized infrastructure
- Production extension points

## Demo script

1. Run API and UI.
2. Ask: "Plan my week, create grocery reminders, track bills, and prepare a travel checklist."
3. Show selected agents.
4. Show created tasks.
5. Show memory updates.
6. Show background job endpoint.
7. Explain enterprise extension.
